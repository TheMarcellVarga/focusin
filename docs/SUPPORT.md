# Focusin Support

Focusin is not yet publicly distributed. A monitored public support contact must be assigned before release.

## Before reporting an issue

- Confirm the Focusin version/build and your macOS version.
- Check notification permission, Focusin’s notification preference, and quiet hours for reminder issues.
- Check Login Items in System Settings for launch-at-login issues.
- Relaunch Focusin and note whether an active focus or break timer restores correctly.

## What to include

- Focusin version/build and installation source.
- macOS version and Mac architecture.
- What you expected and what happened.
- Reproduction steps and approximate timestamp/timezone.
- Relevant screenshots or crash diagnostics with personal information removed.
- The activity title or ID if a wellness prompt felt unsafe or unsuitable.

Do not send unrelated personal data, notification contents, or broad system diagnostics. Focusin has no account or server-side user record.

## Safety

Activities are optional. Stop or skip any prompt that causes discomfort or is unsuitable for your surroundings. Focusin provides general-wellness prompts, not medical advice.

## Contact

Not yet assigned. This is an explicit release blocker, not an active support channel.
